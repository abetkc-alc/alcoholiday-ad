## 21:06　【気になったこと】
おそらく **Remotion（リモーション）** のことですね。

**Remotionのスキルは、Claude CodeなどのAIに「コードで動画を作る手順やコツ」を教えるもの**です。公式では `remotion-best-practices` などが公開されています。[公式スキル一覧](https://github.com/remotion-dev/remotion/blob/main/packages/skills/README.md)

主に、次のような内容が含まれます。

| 内容 | 動画でできること |
|---|---|
| 文字のアニメーション | タイトルを動かしたり、順番に表示したりする |
| 画像・動画の配置 | 写真や動画素材を組み合わせる |
| タイミングの調整 | 何秒目に何を表示するか決める |
| 音声の扱い | BGMやナレーションを組み込む |
| デザイン | フォント、レイアウト、視覚効果を整える |

これらは公式の動画制作スキルで扱われています。[スキルの内容](https://github.com/remotion-dev/remotion/blob/main/packages/skills/skills/remotion-markup/SKILL.md)

たとえば、**「この商品画像を使って、文字が動く15秒の紹介動画を作って」**という依頼に使えます。

役割でいうと、**Remotionは動画を作る道具、スキルはその道具をAIが使うための手引き**です。スキルを入れるだけで完成するわけではなく、動画制作にはRemotion本体や実行環境も必要になります。

**Discordのスキルは、AIがDiscord上の情報を読んだり、操作したりするための手順をまとめたもの**です。ただし、作者や配布元によって内容が違います。

具体的なスキルはまだ特定できていませんが、用途としては次のようなものがあります。

- **会話の要約**：チャンネルのやり取りから、決定事項や未完了の作業をまとめる
- **情報の検索**：過去の発言や関連する会話を探す
- **投稿**：指定したチャンネルへお知らせや作業結果を送る
- **サーバー管理**：チャンネルやロールなどを管理する

実際にできることは、そのスキルの内容と、接続に使うBotなどの権限によります。

見かけたDiscordスキルのリンクや紹介文はありますか？ それがあれば、具体的な機能や必要な設定を説明できます。

## 21:07
**Playwrightのスキルは、Claude Codeにブラウザを操作させて、Webサイトの動作や表示を確認するためのもの**です。

このPCの確認したフォルダには入っていなかったため、公開されている **`lackeyjb/playwright-skill`** を例に説明します。同名・類似のスキルは複数あります。

主な内容は次のとおりです。

| 機能 | できること |
|---|---|
| ブラウザ操作 | ページを開く、ボタンを押す、フォームに入力する |
| 動作テスト | ログインやページ遷移が正常に動くか確認する |
| 表示確認 | PC・スマホの画面サイズで表示を確認する |
| スクリーンショット | ページ全体を画像として保存する |
| リンク確認 | リンク先や遷移を確認する |
| テストの再利用 | 操作をスクリプトとして保存し、繰り返し実行する |

スキルには、**「操作後のページを確認するまで成功と報告しない」「固定の秒数待ちではなく、要素が操作可能になるのを待つ」**など、確認を安定させる指示も含まれています。実行にはNode.js 20以上とPlaywrightなどのセットアップが必要です。[スキルの原文](https://github.com/lackeyjb/playwright-skill/blob/main/skills/playwright-skill/SKILL.md)

たとえば「このサイトをスマホ幅で開いてスクショを撮って」「ログインして管理画面が表示されるか確認して」といった依頼に使えます。
