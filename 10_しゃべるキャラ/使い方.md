# しゃべるキャラ「ホリィ」（2026-10-31）

古い iPad に映したキャラクターと、声で話せるしくみ。頭の中身は ChatGPT（OpenAI）。

## しくみ
- パソコン：`server.py` が ChatGPT と話し、返事を声（mp3）にする。キーはパソコンの `.env` だけ
- iPad：Safari でパソコンの住所を開くだけ。古い iPad でも動く書き方にしてある
- 話しかけ方：iPad のキーボードの **マイクのボタン** で話す →「話す」

## はじめの準備（1回だけ）
1. OpenAI のサイトで API キーを作り、`.env` に `OPENAI_API_KEY=キー` を1行足す（ChatGPT の月額プランとは別に、使った分だけの料金がかかる）
2. iPad の「設定」→「一般」→「キーボード」→「音声入力」をオン
3. iPad の「設定」→「画面表示と明るさ」→「自動ロック」を「なし」にすると、ずっと映しておける

## 毎回の使い方
1. `キャラと話す（ダブルクリックで起動）.bat` をダブルクリック
   - 初回に「ファイアウォール」の確認が出たら「プライベート ネットワーク」を許可
2. 黒い画面に出た `http://192.168.…:8765` を、同じ Wi-Fi の iPad の Safari で開く
3. 共有ボタン →「ホーム画面に追加」すると、次からはアイコンで開ける

## 変えたいとき
- 性格・話し方：`性格.txt`
- 名前・声・ChatGPT のモデル：`設定.json`（声は coral／nova／shimmer／alloy など）
- 吹き出しをタッチ：もう一度言ってくれる／「はじめから」：会話を忘れる
