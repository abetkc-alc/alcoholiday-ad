# scripts（台本部）

## 結論（この部署の仕事）

1つの指示につき、次の3つをセットで **2〜3案** つくる。

1. **動画の構成表**（何秒に何を映すか）
2. **画面に出す文字**（短いコピー）
3. **SNSの投稿文**（Instagram／TikTok／X の3種類）

できた案は `成果物/<指示番号>/台本-案A.md` のように保存し、`board.json` に本文ごと登録する（管理ページで読めるようにする）。

## 動画の構成表 — 今の標準（実写2アングル型・約17秒）

| 時間 | 映すもの |
|---|---|
| 0.0〜3.6秒 | angle1（引き）の実写動画 |
| 3.6〜4.0秒 | 黒に一度落としてつなぐ |
| 4.0〜8.5秒 | angle2（寄り）の実写動画 |
| 8.5〜12.1秒 | ポスターへゆっくり近づく |
| 12.1〜12.9秒 | 近づいたまま止める（ポスターをはっきり見せる） |
| 12.9〜14.4秒 | 商品のサイズ比較写真（動かさない） |
| 14.4〜約17.2秒 | **ALCOHOLIDAYの締め画像＋ナレーション「お酒との時間をもっと楽しく」**（毎回必ず） |

- design の写真はアングル違いで複数枚ある。上の表は2アングルの場合で、使う角度が増えたら実写の区間（1本約4〜5秒、間に黒フェード0.4秒）を足していく。角度ごとに何を見せるか（部屋の雰囲気→ポスターの絵柄→お酒の時間…）で文字を出すタイミングを決める
- 尺は素材の長さに合わせて決める。AI動画は1本5秒。**足りない分をループ・逆再生・長い静止でごまかさない**
- 最後の締め画像＋ナレーションは**どの動画にも必ず入れる**（尺が延びてもよい）

## 画面に出す文字のルール

### 最初のつかみ（フック）は必ず「NO ○○, NO LIFE.」（2026-09-27 社長決定）

- どの商品も、動画の最初の文字はポスターと同じ英語の一文にそろえる
  - ワイン「NO WINE, NO LIFE.」／ウイスキー「NO WHISKY, NO LIFE.」／ビール「NO BEER, NO LIFE.」
  - 日本酒「NO JAPANESE SAKE, NO LIFE.」／スパークリング「NO SPARKLING WINE, NO LIFE.」
- 日本語のコピーは、そのあとに続ける

### 文字は「映画の字幕」のように（2026-09-27 社長決定）

- 画面の下の方・中央に、落ち着いた大きさの白い文字（太すぎない）
- 縁取りは細く、うっすら影を付けて読みやすくする程度。派手な飾りはしない
- 1行・8〜9文字までのルールは同じ


- **1行・8〜9文字まで**（句読点込み）。長いと勝手に2行に折り返される
  - 良い例：「夜景と、乾杯を。」「雨の夜も、乾杯を。」「一献の、贅沢を。」「泡は、今日も踊る。」
  - 過去の失敗：12〜14文字にしたら画面で2行になってしまった
- フォントは太いゴシック（思源黒体・極太）
- 文字は白。明るい背景のときは黒か濃いグレー
- 「NO WINE, NO LIFE.」のような大きな英語の一言を冒頭1.5秒に出す「つかみ」型も実績あり

## SNSの投稿文の型（実際に使ったもの）

**Instagram／TikTok**（3行＋ハッシュタグ）

```
<情景の一言。>
<〇〇の時間を彩る一枚を、部屋に。>
ALCOHOLIDAYのポスターはAmazonストアで。

#ALCOHOLIDAY #〇〇のある暮らし #ポスターインテリア #家飲み ...
```

**X**（短く＋AmazonストアのURL）

```
<情景の一言。>
「NO 〇〇, NO LIFE.」ポスター。
https://www.amazon.co.jp/stores/ALCOHOLIDAY/page/F79A1788-B8AA-4248-973D-17D360788C0C
```

### 実例

| 商品 | 1行目 | 雰囲気 |
|---|---|---|
| ワイン | 光が変わると、いつもの一杯も少し変わる。 | 雑誌調・光のある食卓 |
| ビール | 相手がいなくても、乾杯はできる。／ポスターは、たぶん飲みません。 | 少し笑える |
| ウイスキー | 今夜の一席を、少しだけ特別に。 | 雑誌調・静かな夜 |
| 日本酒 | 静かな夜に、一献の贅沢を。 | 和・落ち着き |
| スパークリング | 小さなお祝いに、今日も泡は踊る。 | お祝い |

## 書くときの考え方

- 「雰囲気が良い」だけでは売れない。**誰向けか・何の商品か・なぜ欲しくなるか**が伝わるようにする
  - 過去に「雰囲気は良いが、商品・誰向けか・買う理由が伝わりにくい」と指摘を受けた
  - 改善例：「ワイン好きの部屋に、これ一枚。」→「ALCOHOLIDAY / Amazonで販売中」
- お酒好きがクスッとする・共感する一言がよい
- その時期の季節・行事・流行に合わせる
- 投稿文の最後は必ず Amazon への案内（Instagram はプロフィールのリンクへ誘導）

## ルール

- 値段など事実を書くときは、根拠を確認してから書く
- 過去の台本は上書き・削除しない
