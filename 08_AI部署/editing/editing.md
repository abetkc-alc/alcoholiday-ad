# editing（編集部）

## 結論（この部署の仕事）

1. 社長が「動画に使う」で選んだ写真（`selected.designFiles`、選んだ順）を、1枚ずつ **Higgsfield（ヒッグスフィールド）で5秒の動画**にする
2. scripts の台本どおりに、ffmpeg（動画を組み立てる道具）で **1本のSNS動画**に仕上げる
3. できた動画を**必ずコマ（静止画）に書き出して目で確認**してから、管理ページに出す

**お金がかかる作業（Higgsfield の生成）は、1本ごとに金額を確認し、やり直しの前には必ず社長に確認する。**

## 1. Higgsfield で動画にする

- 使うモデル：`kling-video/v2.5-turbo/standard/image-to-video`
- 長さ：5秒（1本 約0.18ドル）。10秒は約0.36ドル
- APIキー：Windows の環境変数 `HF_KEY` に保存済み
- 手順：画像をアップロード → 料金の見積もり → 1本0.25ドル以下なら実行 → 完成動画を保存
- 見本スクリプト：`C:\Users\abetk\Documents\Codex\2026-09-19\chatgpt-alcoholiday-sns-alcoholiday-instagram-x\outputs\generate-kling-concept-v2.ps1`
- 同じ名前のファイルがすでにあれば生成しない（二重課金を防ぐ）

### 指示（プロンプト）のコツ — 失敗から学んだこと

| やること | 理由 |
|---|---|
| 最初に「カメラは三脚のように完全固定、ズーム・寄り引き・揺れなし」と強く書く | 書かないとポスターがじわじわゆがむ・動く |
| `cfg_scale`（元の写真にどれだけ忠実か）は **0.9〜0.95** | 低いとポスターが崩れる |
| 0.95 でポスターの絵が意味不明な文字に崩れたら **0.92** に下げてやり直す | 2回起きた |
| 「ポスターの文字を読めるように」「寄って見せる」とは**絶対に書かない** | AIが勝手に文字を描き足す（3回失敗した） |
| カメラを完全に止めすぎない。植物が揺れる・光が変わるなど、周りの小さな動きを入れる | 動きがゼロだと「静止画を載せただけ」と言われる |
| negative_prompt（禁止リスト）に必ず入れる | `poster warping, poster bending, perspective change, garbled text, nonsense text, fake text, cursive text, handwriting, watermark, ghost text, any text not in the original image, bird, flying animal, new objects, added captions` |

| **動かすものを1つだけ決め、「ほかは全部完全に静止」と書く** | いくつも動かそうとすると、何も動かないか、葉っぱが舞い散るなど暴れる。1つに絞ると安定する（2026-09 の実績） |

実績（2026-09-27、ワイン金曜の夜）：見積もりは1本 **0.116ドル**（5秒・cfg 0.9）。動かしたもの：ろうそくの炎（控えめ）／足を伸ばす（はっきり動く・形も自然）／ひざ掛けの房（ほぼ動かない）。人の足を動かす場合は negative_prompt から `people` を外し、`extra legs, deformed feet, face, upper body` を入れる。
見本スクリプト：`08_AI部署/editing/成果物/2026-09-27-01/generate-kling-v1.ps1`

実績（2026-10-03、ビール秋の夕方）：見積もりは1本 **0.179ドル**（5秒・cfg 0.9。9/27 の0.116ドルより上がっていた。2026-10-03 社長承認で管理ページの目安も1本0.18ドルに変更済み）。動かしたもの：ビールの炭酸の泡（よく動く・自然）／カーテン（よく揺れる・壁の光も自然に変わる）／花瓶の紅葉の枝（ほとんど動かない）。
- **negative_prompt に steam・bird を入れても、Kling は2秒過ぎから湯気や鳥を足してくることがある**（今回：冷たいビールの上に湯気、窓の外に鳥2羽）。プロンプトで「窓の外は止まったまま」と書いても出た
- 見つけ方：最初のコマと各コマの差を画面全体で白く表示する「差の地図」を作ると、動いた場所がひと目でわかる（例 `成果物/2026-10-03-01/check/diff-map.png`。作り方：1,2,3,3.6,4.1,4.45秒のコマと最初のコマの明るさの差の最大値を4倍して白黒画像にする）。コマを0.4秒おきに並べて目で見るのも併用
- 直し方（お金をかけない）：湯気・鳥が出た場所が**本来まったく動かない所（壁・空）**なら、その四角だけを最初のコマの絵で覆う（ふちを4〜6pxぼかす）。`成果物/2026-10-03-01/fix_clips_v1.py`／`fix_clips_v2.py`。泡のすぐ上の湯気は、覆う範囲を泡のふちまで広げないと細い筋が残る。動かしたいもの（泡・カーテン）には重ねない。元の素材は残し `-fix.mp4` の別名で保存し、報告に「覆って消した」と必ず書く

### 変なものが映り込んだとき

- まず**元の写真そのもの**を隅々まで確認する（過去に、元の写真に小さな鳥が描かれていたのが原因だった）
- 元の写真に原因があれば、プロンプトではなく写真を直す（その部分だけぼかす）→ design に差し戻す

### 仕上がりの規格

- 縦 1080×1920、30コマ/秒、H.264＋AAC、yuv420p
- 尺は約14〜17秒（締めの分で延びるのはOK）

### 標準のつなぎ方（実写マルチアングル型）

選ばれた写真の数だけ実写をつなぐ（2〜4本が目安。1本約0.18ドルかかるので、本数と金額を先に社長に伝える）。

1本目の実写 → **黒に落とすフェード（0.4秒）** → 2本目の実写 → （3本目以降も同じくフェードでつなぐ）… → 最後の実写 → ポスターへゆっくりズーム → **ズームを0.8秒止める** → サイズ比較写真（動かさない） → 締め画像＋ナレーション

### 必ず守ること

- **ポスターを動かさない（2026-09-27 社長指示）**。後からのズーム（寄り・引き）も禁止。クローズアップは design のクローズアップ写真をそのまま実写化して使う
  - 2026-09-27 v2 で、Higgsfield の動画の中でポスターの絵が額の内側で少しずつ小さくなっていた（5秒で約3%）。さらに編集で寄る動きを足したため「だんだん縮小する」と指摘された
  - 生成後は、`08_AI部署/editing/check_poster.py` でポスターの大きさ・ずれを**数値で確認**する（`python check_poster.py 動画.mp4 x0 y0 x1 y1 "2.5,3.5,4.5,4.9"`。範囲は額の内側を割合で指定し、人やランプがかぶらないよう絞る）
    - 色や黒い線で測る方法はランプの光や人の髪を拾って数字がぶれた。最初のコマと重ね合わせて「何%拡大・何pxずらすと一致するか」で測る方法が確実
    - Kling は**最後の0.5秒ほどでポスターが縮みやすい**（2026-09-27 アップの素材：4.5秒まで100%、4.9秒で99%）。組み立てでは各素材の最初の4.5秒だけを使うので、使う範囲が OK なら作り直し不要
- 湯気・煙・もや・光のにじみが出ないよう、negative_prompt に `steam, smoke, vapor, mist, haze, fog, light bloom, light rays` を入れる（2026-09-27 クローズアップで「湯気が見える」と指摘）
- 文字は映画の字幕風（[[scripts]] のルール）。最初の文字は「NO ○○, NO LIFE.」

- **最後は毎回、締め画像＋ナレーション**。音楽は締めの前に消し、ナレーションだけを流す
- **ループ・逆再生・長い静止で尺を伸ばさない**（社長から禁止されている）。文字を読ませるための1〜2秒の静止はOK
- 尺が足りなければ、Higgsfield で追加の素材を作る（お金がかかるので先に確認）

### 技術的な落とし穴（ハマった所）

- angle1→angle2 を重ね合わせ（ディゾルブ）でつなぐと、ポスターが二重になってゆがんで見える → `xfade=transition=fadeblack` を使う
- ズームは `crop` ではできない（大きさが最初の値で固定される）→ `zoompan` を使う
- ズームは最後まで動かし続けない。止める区間を作る（`if(lt(on,しきい値), ズーム式, 最大値)`）
- 最後のコマを止め絵にするときは `trim`＋`loop` ではなく `tpad=stop_mode=clone` を使う（`trim` は時間がずれると**何も言わずに映像が消える**）
- `trim=end=7` のように、素材（5秒）より長く切り出しても伸びない。先に素材の長さを確認する
- 締め画像（JPEG）は `scale=in_range=jpeg:out_range=tv,format=yuv420p` で色の範囲をそろえてからつなぐ
- 日本語を含む PowerShell スクリプトは **UTF-8（BOM付き）** で保存する（文字化けしてエラーになる）
- `ffmpeg -i` が表示する長さは信用しない。**最後の方のコマを実際に書き出して**映像があるか確認する

## 人物が話しかける動画（2026-10-03-02 Tシャツ「1966 ISLAY WAS FRUIT」で初めて作った）

- **話す人物は Kling 3.0（`kling-video/v3.0/std/image-to-video`）**。`sound` は `"on"`/`"off"` の文字で指定（true/false はエラー）。5秒：音あり約0.54ドル、音なし約0.36ドル。`negative_prompt` は効いているか不明なので、避けたいことはプロンプト本文の最後に「Avoid: …」で書く
  - 音なしでも、プロンプトにセリフ（ローマ字）を書くと口がしっかり動いた。真顔のまま5秒間、文字も顔も崩れなかった
- Higgsfield のモデル一覧は `GET https://api.higgsfield.ai/models` で見られる。見積もり（`/estimate/<モデル>`）は無料で、間違った項目を送るとエラー文で正しい形を教えてくれる
- **Tシャツの文字は、布が動くと崩れる**。すそを引っぱる動きを入れたら、Kling 2.5 でも 3.0 でも1.3秒あたりから文字が斜体のようにゆがんだ。笑顔の場面も、Kling 2.5 では「1966」の6が変形した（3.0 では3.5秒まで無事）
  - 対策：素材を0.125秒ごとに拡大して並べ、**文字が崩れていない区間だけを切り出して使う**。次からは、プリントの近くの布を動かす指示は出さない（背景の光・呼吸・表情だけを動かす）
- 組み立てで本編を無音にするとき、`anullsrc` を filter の中で作ると終わりが来ず、ffmpeg がメモリを使い続けて止まった → `-f lavfi -t <秒> -i anullsrc=...` のように**長さを決めた入力**にする
- 冒頭に入れたデザイン画像（PNG）は背景が透明だった → 白地に重ねてから使う
- 見本：`成果物/2026-10-03-02/generate-kling-v2.ps1`（Kling 3.0）／`build_video_v1.py`（デザイン画像→人物3場面→締め、字幕を口の動きに合わせる。口の動きは口元の四角の明るさの変化をコマごとに数字にして調べた）
- **セリフの声も Kling 3.0 で作れる**（`sound:"on"`、5秒 約0.54ドル）。プロンプトに日本語のセリフを「」付きでそのまま書き、「calm, low, quiet female voice」「no music, no other voices」と指定したら、セリフどおりの日本語を口の動きとそろえて話した（2026-10-03 v3）
  - 声が正しいかは、私（Claude）は聞けないので **faster-whisper で文字起こしして確認**する（`pip install faster-whisper`、モデル small、`language='ja'`、`word_timestamps=True`）。ファイル名を渡すとエラーになったので、wav を numpy の配列にして渡す。表示が文字化けするときは `PYTHONIOENCODING=utf-8`
  - 文字起こしの単語ごとの時刻を、そのまま字幕の表示時刻に使える（`build_video_v2.py` の `at()`）
- 人物の写真を作り直すときは、**プリント全体（上から下まで）が画面に入る構図**を指定する。バストアップにしたら「WAS FRUIT」が切れて「文字が一部消えている」と指摘された
- 笑顔は「soft, gentle, closed-mouth smile, no teeth」「肩・胸・Tシャツは動かさない、顔だけ変わる」と書くと、やわらかく、文字も5秒間崩れなかった
- **Tシャツのアップは、布を動かさない指示でも約0.8秒で文字（F・R）が傾き始めた**（Kling 3.0・v5）。何度作り直しても同じになりやすい
  - お金をかけない直し方：`成果物/2026-10-03-02/fix_closeup_print.py`。文字が崩れていない**最初のコマのプリント部分（布ごと）**を、各コマの胸の位置に重ねる。背景の光・髪・手は素材のまま
  - 位置合わせの注意：①プリントの黄色は胸のあたりだけで探す（背景の電球・肌を拾って画面全体を範囲にしてしまった）②ずれを探す範囲は広く（カメラがゆっくり動き、2秒で50px動いた。±14px では元の文字が二重に残った）③測ったずれはコマごとにばらつくので、時間の2次式でなめらかにしてから重ねる（そのままだとガタガタ揺れる）
  - 元の素材は残し、`-fix4.mp4` のような別名で保存。報告には「最初のコマのプリントを重ねて直した」と必ず書く
- 冒頭のデザイン画像を「透かす」とき：デザイン（背景透明）の下に白いもや（55%）をかけて、①の映像の上に0.75秒重ね、0.3秒で消した（`build_video_v3.py`）
- 声と音楽を重ねるときは、声の間の曲を 0.10 倍くらいまで下げる（0.16 だと声との差が小さかった）。カモメなどの効果音は `adelay` で切り替えの瞬間に合わせる
