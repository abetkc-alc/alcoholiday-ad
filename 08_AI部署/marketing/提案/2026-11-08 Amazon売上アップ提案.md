# Amazon 売上アップ提案（2026-11-08）

## 結論

- **いちばんの問題は「お店に来る人が少なすぎる」こと**。商品ページを見た人は1日 約15人だけ。来た人が買う割合（4.2%）は悪くない
- そこで、**① 売る商品を3つにしぼる → ② その3つのページを直す → ③ 1日1,000円を「買う気のある人の検索」にだけ使う**、の順で進める
- いちばん大事なのは「**毎週、決めた数字を見て、決めた基準で止める・増やす**」こと。これまで成果が出なかったのは、ここが無かったからの可能性が高い
- 正直に言うと、**1日1,000円の広告だけで月100万円は届かない**（Codex・Gemini とも同じ意見）。まずは 3か月で月15〜25万円 を目指し、利益が出たら広告費を少しずつ増やす

## 今の数字（2026-05-08〜11-07 の6か月）

| 項目 | 今 | 月100万円に必要 |
|---|---:|---:|
| 1か月の売上 | 約49,000円 | 1,000,000円 |
| 1か月に売れる数 | 約20個 | 約310〜400個 |
| 1個の平均の値段 | 約2,480円 | 3,000円台（セット販売で上げる） |
| ページを見た人（1日） | 約15人 | 約130〜320人 |
| 見た人が買う割合 | 4.2% | 6〜8% |

- 去年の同じ時期とほぼ同じで、伸びていない。10月からは少し下がっている
- 5/8・8月中旬の大きな山は、まとめ買いなどの「たまたま」の可能性が高い。良し悪しは1日の山ではなく、**4週間の平均**で見る

## Codex と Gemini の意見の見比べ（KAYO が確かめた）

| こと | Codex | Gemini | KAYO の判断 |
|---|---|---|---|
| いちばんの問題 | 人が来ない（買う割合も直せる） | 人が来ない | **同じ意見。人を増やすのが先** |
| 売る商品 | 主力3〜5つにしぼる | ― | **3つにしぼる**（下の「商品えらび」） |
| メイン画像（検索で最初に出る写真） | 白い背景に商品だけ | 部屋に飾った写真 | **Codex が正しい**。Amazon のきまりでメイン画像は白い背景。部屋の写真は2枚目以降に使う |
| 広告の種類 | 商品の広告が中心＋ブランド広告を少し | 商品の広告だけ | **はじめの2週間は商品の広告だけ**（お金が少ないので一点集中） |
| 売れない言葉を止める基準 | 20回クリック・0個で止める | 50回クリック・0個で止める | **Codex の20回**（1回40円なら約800円で判断できる） |
| ブラックフライデーの広告費 | 1,000円のまま、売れる言葉へ寄せる | 1日1,500円に増やす | **1,000円のまま**（タケシの上限を守る） |
| レビューを増やす | Amazon Vine（公式の無料レビュー） | Amazon Vine | **同じ意見。主力に申し込む**（費用はセラーセントラルで確認） |
| 月100万円まで | 9〜18か月。広告だけでは無理 | 6か月〜1年 | **Codex の方が現実的** |

- Gemini は使える量の上限にかかり、軽い版で答えた。そのためか、まちがい（メイン画像・広告費）があった
- ブラックフライデーは「11月中に開催、**日程は11月19日の朝に発表**」と Amazon が発表済み（KAYO が確認）
- クーポンやセールの手数料、Vine の料金、FBA の納品の締め切りは Codex の調べ。**セラーセントラルで必ず確かめてから使う**

## やること（日付つき）

### 11月8日〜13日：準備（お金はかけない）

1. **主力の3商品を決める**（商品えらびの考え方）
   - 過去6か月で一番売れたポスター2つ ＋ 一番売れた Tシャツ（または3つ目のポスター）
   - 例：NO WHISKY, NO LIFE.／NO WINE, NO LIFE.／ビール か 日本酒
2. **その3商品のページを直す**
   - メイン画像：白い背景・商品が大きく・スマホでも文字が読める
   - 2枚目以降（7枚）：部屋に飾った写真／人や家具と並べた大きさ比べ／紙と印刷の近くの写真／サイズ・額縁の有無／包み方／シリーズの一覧
   - 題名：「何の商品か・だれ向けか・大きさ」を前に
     例：「ALCOHOLIDAY NO WHISKY, NO LIFE. ポスター お酒・ウイスキー好きのインテリア雑貨 A3 額縁なし」
   - 説明（箇条書き）：デザインの意味 → 大きさ → 紙と印刷 → 額縁の有無 → 包み方・贈り物に
   - 「お酒そのものではなく、雑貨です」とはっきり書く
3. **Amazon Vine に主力1つを申し込む**（まず2個）
4. ブラックフライデーに向けて、主力の在庫をふだんの3〜4倍にする（FBA の場合）

### 11月14日〜18日：広告を始める（1日1,000円）

> [!warning] 2026-11-08 追記：広告の実績を見て、この下の表より **[[2026-11-08 広告の実績の分析]] の「これからの広告」を優先**する（止めてある自動広告「2回目ポスター」を、ワイン・ビールだけ・おすすめ値段・1日1,000円に直して再開）。主力はワイン・ビール。ウイスキーはページを直してから。

| 広告 | 1日 | 中身 |
|---|---:|---|
| 自動（Amazon にまかせる） | 300円 | 売れる言葉を見つける係 |
| 手動・ぴったりの言葉 | 400円 | 買う気のある言葉（下の一覧） |
| 手動・言葉をふくむ | 150円 | 似た言い回しを拾う |
| 似た商品のページに出す | 150円 | ほかの酒ポスター・酒雑貨のページ |

- 1回のクリックの値段の目安：30〜60円から。最初は「下げるだけ」の自動調整
- 入れる言葉（ポスター）：お酒 ポスター／お酒 インテリア／お酒 雑貨／バー ポスター／ウイスキー ポスター／ウイスキー グッズ／ウイスキー好き プレゼント／ワイン ポスター／ワイン好き プレゼント／ビール ポスター／ビール好き プレゼント／日本酒 グッズ／日本酒好き プレゼント／お酒好き プレゼント／晩酌 グッズ
- Tシャツは別の広告にする（ウイスキー Tシャツ／お酒 Tシャツ／アイラ ウイスキー グッズ）
- 出さない言葉：通販／ボトル／750ml／酒屋／ノンアルコール／レシピ／作り方／無料／中古
- 同時に **5%クーポン** を主力3つに5日間つけて、つける前と買う割合をくらべる

### 11月19日：ブラックフライデーの日程が出る

- 主力1〜2つにセール価格（15%引き）か、5〜10%クーポン（安い手数料の方）
- 広告は主力3つだけ。売れた言葉に多く回す（合計は1,000円のまま）
- Instagram は「Amazon で○%引き・○日まで」と、商品ページへ直接案内

### 12月1日〜25日：クリスマス

- 「お酒好きの夫・父・友だちへ」「お酒は好みがむずかしい。雑貨なら贈りやすい」
- **2枚セット**（ウイスキー＋ワインなど）を、単品の合計より1割ほど安く → 1回の買い物の金額を上げる
- ブランドストアの一番上を「お酒好きへの贈り物」に

### 12月26日〜1月5日：年末年始

- 「新しい年に部屋を模様替え」「家飲みの場所を整える」に言いかえる
- クリスマスの言葉の広告は止め、12月に売れた言葉だけ残す

## 毎週月曜に見る数字（marketing 部が表にする）

| 数字 | 見方 |
|---|---|
| ページを見た人 | 前の4週の平均より増えているか |
| 見た人が買う割合 | 6%より下なら、ページ・値段・レビューを直す |
| 広告のクリック率 | 0.3%より下が続くなら、写真か言葉を直す |
| 広告費 ÷ 広告からの売上（ACOS） | 利益が出る線より下か（線は原価が分かれば計算する） |
| 言葉ごとの売れた数 | 売れた言葉は「ぴったり」の広告へ移したか |

**止める・増やす基準**
- 12回クリックされて0個 → その言葉の値段を2割下げる
- **20回クリックされて0個（または約750円使って0個）→ 止める**
- 2個以上売れて、広告費が売上の3割以下 → 値段を1割上げる
- **変えるのは1週間に3つまで**。毎日いじらない
