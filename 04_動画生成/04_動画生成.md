# 04_動画生成

AIで動画を自動生成してSNSへアップするための情報を置く場所。

- 動画の台本・構成案
- AIに出す指示（プロンプト）のメモ
- 使った素材（画像・音楽など）の管理
- 生成した動画の一覧・投稿先の記録

## 採用する動画作成サービス

- Creatomateを使用する
- 商品画像・字幕・ロゴをテンプレートに差し込み、Instagramリール用の縦動画を自動生成する
- ポスターが主役のため、毎回異なる部屋に飾ったように見える背景を用意し、実物のポスター画像を合成する
- 部屋の背景は、最初は複数パターンを用意して順番に使い、安定後にAIで毎回生成する方法を検討する
- 最初は動画を自動生成して確認待ちにするところまで作る
- Instagramへの自動投稿は、動画生成が安定してから公式APIで追加する

## 次に行うこと

1. Creatomateのアカウントを作成する
2. 9:16、15〜30秒の商品紹介テンプレートを1つ作る
3. 商品画像とロゴを登録する
4. APIキーを発行する
5. Googleスプレッドシートまたは管理表から動画を生成する仕組みを作る

## ポスター動画の作り方

1. ポスターが飾られていない部屋の背景画像を用意する
2. 背景画像に実物のポスター画像を合成する
3. 合成画像をCreatomateに渡す
4. ズーム、移動、字幕、Amazonショップへの案内を追加して動画にする
5. 人が確認してから投稿する

※部屋の画像をAIに作らせる場合も、ポスターそのものはAIに描き直させず、実物画像を後から合成する。文字やデザインの崩れを防ぐため。

## 実写2アングル動画の作り方(2026-09時点・実際に使っているやり方)

Creatomate案は保留中。現在はこちらの方法で作っている。

### 全体の流れ(結論)

1. ポスターを飾った部屋の写真を**2枚**用意する(引きの構図=angle1、ポスターに寄った構図=angle2)
2. その2枚をHiggsfield(Kling AIの動画生成サービス)に渡し、それぞれ5秒の短い実写動画にする
3. できた2本の動画をffmpegでつなげて1本のSNS動画にする
   - angle1の実写5秒 → 黒に一度落としてフェード → angle2の実写5秒 → ポスターへゆっくりズーム → 最後0.8秒は静止(はっきり見せる)
   - → 商品のサイズ比較写真(静止) → ALCOHOLIDAYの締め画像+ナレーション
4. 人が確認してからSNSに投稿する

### Higgsfield(Kling)に頼むときのコツ

- プロンプトの最初に「カメラは三脚のように完全固定、ズーム・寄り引き・揺れは一切なし」という強い一文を入れる(これがないとポスターがじわじわ歪んだり動いたりする)
- `cfg_scale`(元画像への忠実度)は0.9〜0.95にする。低いと自由に動きすぎてポスターが崩れる
- ただし0.95だと稀にポスターの絵柄が意味不明な文字に崩れる事故が起きる → その時は0.92まで下げて作り直す
- 「ポスターの文字を読めるように」「寄って見せる」という言い方は絶対にしない → モデルが勝手に文字を書き足してしまう
- negative_promptに poster warping/garbled text/bird/flying animal などを必ず入れる
- **部屋の元画像そのものに小さい鳥などの絵が描き込まれていることがある**(AIが部屋を生成する際に紛れ込む)。プロンプトをどう直しても動画では動いて見えてしまうので、元画像を先に確認し、いた場合は画像編集(ぼかしで塗りつぶす等)してから動画化する

### ffmpegで組み立てるときのコツ

- angle1→angle2のつなぎは、単純な重ね合わせ(dissolve)だと窓の外の景色が違うと二重写しでポスターが歪んで見える → 一度黒を挟むフェード(`fadeblack`)にする
- ポスターへのズームは、最後まで動かし続けると「不自然に動いている」と感じられる → カットの直前0.8秒はズームを止めて静止させる
- 参考スクリプト: `build-livingroom-sns-final-v7.ps1`(次回はこれをコピーして商品名・素材パスだけ差し替えるのが早い)

### 次に新しい商品の動画を頼むときのプロンプト例(コピペ用)

> 「〇〇(商品名)のSNS動画を作って。04_動画生成のノートにある『実写2アングル動画の作り方』と同じ手順(Higgsfieldで2アングル生成→ffmpegで組み立て)で進めて。部屋の写真(angle1・angle2)は[用意済み/まだない]。」

部屋の写真がまだない場合は、先に「〇〇のポスターを飾った部屋の写真を2枚(引きの構図と、ポスターに寄った構図)用意して」と頼む。
