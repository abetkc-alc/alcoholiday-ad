# ALCニュース（ショート動画作成の別バージョン・試作）

視聴者が投稿した動画を、**キー局の報道番組そっくりの縦型ニュース**（ニュースの部分は20秒以内＋最後にブランドボード約5秒）にするサービス。
見た目と話し方は大まじめ、扱う中身はくだらない ＝ シュールな笑い。
いまは **タケシさんだけが試せる試作**（このパソコンの中だけで動く）。

## 使い方（試作）
1. `ALCニュース試作を開く.bat` をダブルクリック → ブラウザで受付ページが開く（http://127.0.0.1:8765）
2. ニュースの種類・①いつ ②どこで ③だれが ④なにを ⑤どうした ⑥状況（300字）・動画を入れて「ニュースをつくる」
3. 2〜3分で動画ができ、その場で再生・ダウンロードできる
- できたものは `案件/<日時>/ALCニュース.mp4`（案件フォルダは GitHub に送らない）

## 動画の流れ（A〜C は20秒以内。D の分だけ長くなり、全体は23〜25秒ほど）
| 場面 | 中身 |
|---|---|
| A キャスター | はじまりの音 →「ALCニュースです。」＋要約1文。右のモニター（グリーンバック）に投稿動画 |
| B 投稿動画（全画面） | 種類で変える（下の表）。テロップ＋「視聴者投稿」 |
| C キャスター | **辛辣でシュールな**一言（笑わず淡々と、報道の口調のまま行動や発言にちくっと刺すツッコミ。見た目・年齢・体をばかにする悪口はなし。2026-11-07 タケシさんの指示。その前の「明るく楽しく」から変更）。「ご視聴ありがとうございました。」は言わない |
| D ブランドボード | ALCOHOLIDAY のブランドボード（`Desktop/ALCOHOLIDAY/画像/商品画像/ORIGINAL/JPG_ending_title.jpg`）＋声「お酒との時間をもっと楽しく」（`Desktop/ALCOHOLIDAY/音声/お酒との時間をもっと楽しく.wav`）。キャスターから0.3秒で切りかえ、約5.4秒（2026-11-07 タケシさんの指示） |

| 種類 | Bロール |
|---|---|
| 明るいニュース | 動画の音そのまま＋テロップ＋字幕（黄色） |
| 困ったニュース | 顔にモザイク＋声を低く変える＋テロップ＋字幕＋「※映像と音声を一部加工しています」 |
| 情報 | 動画の音は小さく、キャスターの声で要約を伝える＋字幕 |

## 決まり（2026-11-07 タケシさんの指示）
- キャスター：**大舞 剛（おおまい つよし）**。決して笑わない・一定の調子・はっきりした読み
- 語尾は推測・伝聞（〜とのことです／〜とみられます／〜した模様です）
- 見た目は NHK・キー局の報道番組そのもの（赤い「ALCニュース」・「速報」・白い見出し・名前のテロップ）
- モニターの右上の見出しは、上に赤い札（小さな白い言葉）、その下に大きな白い字（黒いふちと影）。板は使わない（2026-11-07 タケシさんの直し。緑の帯・黒い板・白い板＋紺の板はやめた）
- キャスターの場面の「視聴者投稿」は、モニターの右下の隅（2026-11-07 タケシさんの直し）
- 名前のテロップは「大舞 剛」の下に英語表記「Omai Tsuyoshi」（2026-11-07）。漢字と英語はまん中をそろえる
- キャスターの字幕は、下の黒い半透明の帯に白い字（2行目は黄色）。帯なし・机を黒くするのを試したが、この形に戻した（2026-11-07 タケシさんの直し）。ロゴの「ニュース」は太字
- 画面の上は2段（2026-11-07 タケシさんの直し「わかりやすく」）：1段目＝番組ロゴ（赤い札に、白い四角3つに赤い「A」「L」「C」＋白い「ニュース」。タケシさんの見本の形で NEWS をカタカナに・四角と字は右へかたむけたイタリック・2026-11-07。`素材/make_logo.py` → `素材/logo-alcnews.png`）。時刻は出さない（2026-11-07）／2段目＝赤い「速報」と白い見出しを横いっぱいに大きく。SNS の名前の表示にかからないよう、上から110px あける。斜めの赤い帯はやめた

- キャスターの字幕は言葉の途中で行を分けない（助詞のあとで分け、なければカタカナ・漢字のまとまりで折り返す。2026-11-07）

- キャスターの顔：タケシさんの写真（`Pictures/Camera Roll/キャスター`）を Codex で加工。38歳ごろ・黒髪のキャスター風・髭なし・メガネなし・紺のスーツ → `素材/キャスター/caster-studio-v2.png`
- キャスターの表情は「やさしい顔」。**笑顔ではない**（口は閉じ、口角は上げない。眉間のしわなし・目もとはやわらかく）（2026-11-07 タケシさんの直し。v1 はにらんでいるようでこわかった）

## しくみ
- `tools/alc_news.py`：書き起こし（Gemini）→ 台本（claude -p）→ 声（Google Chirp3-HD-Charon・速さ1.12）→ 組み立て
- `tools/app.py`：受付ページ（127.0.0.1 だけ。ほかの人からは見えない）
- モザイクは顔を自動で見つける（`素材/face_detection_yunet_2023mar.onnx`）
- 声見本：`声見本/`（Charon・Schedar・Iapetus・Rasalgethi・Neural2-C・Neural2-D）。変えるときは alc_news.py の `VOICE`
- キャスターの映像：
  - **写真のまま（無料）**：中身の確認用
  - **口を動かす（お金がかかる）**：Higgsfield の Seedance 2.5（声を渡すと口を合わせる）。480p・1:1 で1本 約2.3ドル（キャスターが話す約11秒ぶん。2026-11-07 に一度 720p＝約5.1ドルにしたが、タケシさんの指示「安い動画生成で」で 480p に戻した。720p は顔がくっきりする）。Seedance は見積もりを金額で返さないので、料金表の式で計算し、上限3.5ドルをこえたら止まる
    - **Seedance は渡した写真の構図を守らない**：緑一色の背景の前に、少し小さいキャスターと黒い机をつくってくる（2026-11-07 初回）。そのままはめると窓が黒く抜け、机が二重になった
    - 直し方（お金はかからない）：緑を抜いてキャスターだけにし、**両目の幅と位置**を、いつも同じ大きさ（sample-02 の見え方＝タケシさんが見なれたもの。`EYE_MID`・`EYE_DIST`）にそろえて、**空のスタジオ**（`素材/キャスター/studio-empty-v1.png`・Codex でキャスターを消したもの）の上に重ね、手前に机をかぶせる。倍率と位置は毎回自動ではかる（`lip_fit`）。髪・肩のふちは1〜2px けずり、緑の照り返しは全体から取る
    - はじめは「頭のてっぺん〜机の長さ」で合わせていたが、720p では Seedance が後ろの壁に横線を入れ、それを机とまちがえてキャスターが大きくなった（2026-11-07 タケシさんの直し「これまでのサイズと同じに」）ので、目で合わせるやり方に変えた
    - 大きさは、写真のまま（無料）の版と同じ（2026-11-07 タケシさんの直し「右側の写真のキャスターのサイズに」）。目の幅でおおよそを出したあと、モニター（緑）の中に写る写真のキャスターの形（頭と肩の輪郭）に、口の動画のキャスターの形がいちばん重なる大きさと場所を探す（`lip_fit`）。Seedance のキャスターは頭が大きめで体が細めなので、目だけで合わせると体が小さく見えた。輪郭で合わせても顔は5%ほど大きめになる
    - **Seedance は声の「間」も勝手にのばす**：渡した声を、文と文の間を長くして読み直す。そのままだと口が 0.4秒→1.2秒とだんだん遅れた（2026-11-07 タケシさんの直し「口の動きと音声がずれている」）
    - 直し方（お金はかからない）：口の動画についている声と、こちらの声の「音色の並び」を端から端まで照らし合わせ（DTW）、声に合う口のコマを選び直す（`lip_timeline`）。はじめは「声の区間を順に対応させる」やり方だったが、口の動画で区間がつながると使えず、口が最大1.2秒遅れた（2026-11-07 の720p の1本目）ので変えた
    - 見本：`案件/sample-02-口あり`（困ったニュース・2.26ドル）。口は声によく合っている。顔は少しやわらかい（480p を引きのばすため）
