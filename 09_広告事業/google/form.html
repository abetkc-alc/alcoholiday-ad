おすすめ商品の申し込み

ALCOHOLIDAY の SNS でおすすめ商品をご紹介します。

  1. 1お店の詳細を入力
  2. 2おすすめ商品の説明を入力
  3. 3動画をアップロード
  4. 4メールで届いた動画を確認
  5. 5承認から時間以内に自動で投稿（混み合っているときは、順番に投稿するため、もう少し時間がかかることがあります）

全部で7つです

SNS の文に載せます

最寄り駅なくてもよい

SNS の文に載せます

お店の SNSなくてもよい

印をつけておくと、次からも直した内容が最初から入ります

2おすすめの商品

商品の名前必ず

文字まで。動画の上に大きく出します

商品の説明必ず

文字まで。味・こだわり・おすすめの飲み方など

値段なくてもよい

印をつけると、動画に「数量に限りがありますので、品切れの際は予めご了承ください。」の一文を入れます

3お店で撮った動画を3本

スマホで5秒くらいの動画を3本撮ってください。3本をつないで、声の案内と字幕を入れた1本の動画にします。

  • スマホは縦向きで、明るい場所で撮ってください
  • 動画の音は使いません（音楽と声の案内を入れます）
  • 人・商品・場所などが映るときは、掲載の了承をとってください（7 の確認事項をお読みください）
  • 1本 秒まで・MB まで（5秒くらいがおすすめです）。長い動画・大きい動画は送れません。送るのに少し時間がかかります（Wi-Fi がおすすめです）

4SNS に載せる文

動画といっしょに Instagram・TikTok・X に載せる文です。書かなくても大丈夫です（空なら ALCOHOLIDAY が書きます）。

  • 書いた文は Instagram にそのまま載せます。TikTok と X には、短くまとめて載せます
  • 最初に入力したお店の住所・営業時間・電話番号は必ず載せます。
  • 「#PR」「提供：店名」「お酒は20歳になってから」などの決まった文も、自動で付けます
SNS に載せる文なくてもよい

5声の案内の種類

動画の声の案内（ナレーション）の声をえらんでください。「▶ 声を聞く」で聞きくらべられます。

ご要望なくてもよい

6投稿する SNS

動画を載せる SNS に印をつけてください（いくつでも）。
動画を承認していただいてから時間以内に、えらんだ SNS へ自動で投稿します。

  • 同じ SNS への投稿は時間以上あけているため、混み合っているときは順番に投稿します（投稿の時刻は、承認のあとメールでお知らせします）

7確認して申し込む

  • 動画は、お客様に承認していただいてから投稿します。承認がない場合は投稿しません。
  • 動画の直しは1回までです。直したあとは、直す前と直したあとの2本から選んで承認していただきます。
  • 載せる文には、広告であることを示す「#PR」と、お酒の注意書き（20歳未満の飲酒・飲酒運転の禁止）を入れます。
  • 送っていただく動画に映っている場所・人・商品・音楽・看板やロゴなどは、撮影と SNS への掲載について、お申し込みいただいた方が、すべて了承を得ているものとします。
  • 送っていただいた動画・文・お店の情報について、ほかの人や会社とのあいだで問題が起きた場合は、お申し込みいただいた方の責任と費用で解決していただきます。ALCOHOLIDAY は一切の責任を負いません。
  • 紹介による集客や売上などの効果をお約束するものではありません。
  • 声の案内は AI の読み上げです。説明の文は、読みやすい長さに整えることがあります（承認のときに確認できます）。
  • 卑猥な言葉・差別的な言葉・誹謗中傷など、広告にふさわしくない言葉は使いません。書かれていた場合は、別の言葉に置き換えるか、削ります。
