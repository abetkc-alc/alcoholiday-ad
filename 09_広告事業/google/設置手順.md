# BAR広告の受付サイト 設置手順（最初に一度だけ）

> [!success] 進み具合（2026-10-04）
> 手順1〜3・5・6・8 は終わり（Google に設置・パソコンとつないだ・声の見本・本番の声）。**残りは手順4（Upload-Post）と手順7（ホームページからつなぐ）**
> パソコンの自動制作（5分ごと）も登録ずみ：タスク スケジューラーの「ALCOHOLIDAY BAR広告 自動制作」

[[広告事業]] の受付サイト・承認ページ・自動予約を、Google の上に置くための手順です。
全部で **約50分**。むずかしいところは KAYO（Claude Code）に「ここがわからない」と聞いてください。

> [!info] 使うもの
> - Google アカウント：**abetkc@alcoholiday.org**（必ずこのアカウントで操作する）
> - このフォルダの10のファイル：`Code.gs`／`top.html`／`form.html`／`review.html`／`confirm.html`／`logo.html`／`photos.html`／`css.html`／`common.html`／`appsscript.json`
> - Google Cloud の読み上げ（手順8・ふつうは0円）
> - Upload-Post（予約投稿サービス）：月24ドルの「Basic」プラン

---

## 手順1　プログラムの置き場所をつくる（10分）

1. Chrome で **https://script.google.com** を開く（右上が abetkc@alcoholiday.org になっているか確認）
2. 左上の「**新しいプロジェクト**」を押す
3. 左上の「無題のプロジェクト」を押して、名前を **ALCOHOLIDAY BAR広告** にする
4. 最初からある `コード.gs` の中身を全部消して、`Code.gs` の中身を全部コピーして貼りつける
5. 左の「ファイル」の横の **＋** →「**HTML**」→ 名前に **form** と入れる（.html は付けない）→ 中身を全部消して `form.html` を貼りつける
6. もう一度 **＋** →「HTML」→ 名前 **review** → `review.html` を貼りつける
   - 同じように **＋** →「HTML」で、次の6つもつくって貼りつける（名前に .html は付けない）
     - **top** → `top.html`（トップページ：紹介・「申し込む」ボタン。2026-11-03 会員登録はやめた）
     - **confirm** → `confirm.html`（メールの「申し込みを確定する」のページ。2026-11-03）
     - **logo** → `logo.html`（ロゴ。とても長い1行ですが、全部コピーして貼りつける）
     - **photos** → `photos.html`（トップページの写真。これもとても長いですが、全部コピーして貼りつける）
     - **css** → `css.html`（見た目）
     - **common** → `common.html`（声の入力などの共通の動き）
7. 左の歯車「**プロジェクトの設定**」→「**appsscript.json マニフェスト ファイルをエディタで表示する**」にチェック
8. 左の「エディタ」（＜＞）に戻り、`appsscript.json` を開いて中身を全部消し、このフォルダの `appsscript.json` を貼りつける
9. 上のフロッピーの絵（**保存**）を押す

## 手順2　台帳とフォルダをつくる（5分）

1. 上の関数の選び欄で **setup** を選び、「**実行**」を押す
2. 「承認が必要です」→「権限を確認」→ abetkc@alcoholiday.org を選ぶ
   - 「このアプリは Google で確認されていません」と出たら「詳細」→「ALCOHOLIDAY BAR広告（安全ではないページ）に移動」→「許可」
   - ※ 自分で作ったプログラムなので問題ありません
3. 下の「実行ログ」に3つ出ます。**メモ帳にコピーしておく**
   - 受付台帳（スプレッドシート）の場所 … 申込みが一覧でたまる表。ここが社長の管理画面になります
   - Google ドライブのフォルダの場所 … お客さんの写真・完成動画がたまる
   - **API_KEY** … パソコンの KAYO が Google とやりとりする合言葉（人に見せない）

## 手順3　インターネットに公開する（5分）

1. 右上の青いボタン「**デプロイ**」→「**新しいデプロイ**」
2. 歯車 →「**ウェブアプリ**」を選ぶ
3. 次のように設定して「デプロイ」
   - 説明：受付サイト
   - 次のユーザーとして実行：**自分（abetkc@alcoholiday.org）**
   - アクセスできるユーザー：**全員**
4. 出てきた「ウェブアプリ」の URL（`https://script.google.com/macros/s/……/exec`）を**コピーしてメモ**
   - これが **受付サイトの住所（トップページ）** です。お客さんにはこの URL を案内します。会員登録・ログインのあと、受付ページに進みます
5. 左の歯車「プロジェクトの設定」→ 一番下「**スクリプト プロパティ**」→「スクリプト プロパティを追加」
   - プロパティ：`WEB_APP_URL`　値：さっきの URL → 保存

> [!warning] プログラムを直したとき
> 「デプロイ」→「デプロイを管理」→ 鉛筆マーク →「バージョン：新バージョン」→「デプロイ」。
> こうすると URL は変わりません（「新しいデプロイ」を押すと URL が変わってしまうので注意）。

## 手順4　Upload-Post（自動投稿）をつなぐ（15分）

1. **https://www.upload-post.com** で登録（Google アカウントで登録できます）
2. プランを **Basic（月24ドル）** にする（無料プランは TikTok が使えません）
3. 「Profiles（プロフィール）」で新しいプロフィールを作る。名前は **alcoholiday**
4. そのプロフィールに **Instagram・TikTok・X** の @alcoholiday25 をつなぐ
   - Instagram は「プロアカウント（ビジネスかクリエイター）」である必要があります
5. 「API Keys」で API キーを作ってコピー
6. Apps Script の「スクリプト プロパティ」に2つ追加して保存
   - `UPLOAD_POST_KEY`　値：Upload-Post の API キー
   - `UPLOAD_POST_USER`　値：**alcoholiday**（手順3で作ったプロフィール名）
7. `07_アカウント管理/アカウント一覧.md` に「Upload-Post」を1行足す（キーそのものは書かない）

## 手順5　パソコン（KAYO）とつなぐ（2分）

KAYO に次のように話しかけてください。KAYO がパソコンに設定します。

> KAYO、BAR広告の設定をして。URL は ○○、API_KEY は △△

（自分で設定する場合：Windows の検索で「環境変数」→「環境変数を編集」→ ユーザー環境変数に `BAR_API_URL`＝ウェブアプリのURL、`BAR_API_KEY`＝API_KEY を追加）

## 手順6　動作の確認（5分）

1. KAYO に「**KAYO、声の見本を受付サイトに登録して**」→ 受付ページの「▶ 声を聞く」で3人の声が聞けるようになる
   - あわせてスマホで「🎤 話して入力」を押し、声で入力できるか確かめる（できなくても、スマホのキーボードのマイクで入力できます）
2. 受付サイトの URL をスマホで開き、**「はじめての方」からテストの会員登録**をして、そのまま**テストで1件申し込む**（店名に「テスト」と入れる。5秒くらいの動画を3本撮って入れる）
3. 申込みの確認メールが届き、受付台帳に1行増えれば成功
4. テストの申込みは、KAYO に「テストをキャンセルにして」と言えば枠が空きます

## 手順7　ホームページからつなぐ

alcoholiday.org（Google サイト）を編集し、「挿入」→「ボタン」で
「BAR の方へ：おすすめを SNS で紹介します」などの名前で、受付サイトの URL をつなぐ。

## 手順8　本番のナレーションの声（Google の読み上げ）をつなぐ（10分）

> 2026-10-04 済み：プロジェクト alcoholiday-voice・キー名「BAR広告の声」（Text-to-Speech だけに制限）。声は ローズ＝Sulafat／ラフィ＝Aoede／アイラ＝Despina／アルビン＝Orus

お試しでは無料の声（edge-tts）を使っていますが、お金をいただく広告では、使ってよいことがはっきりしている Google の読み上げに切り替えます。
毎月100万文字まで無料なので、この事業の量ならふつうは**0円**です（ただし、支払い用のカードの登録が必要です）。

1. Chrome で **https://console.cloud.google.com** を開く（abetkc@alcoholiday.org）
2. 上の「プロジェクトを選択」→「新しいプロジェクト」→ 名前 **alcoholiday-voice** →「作成」
3. 検索欄に **Text-to-Speech** と入れ →「Cloud Text-to-Speech API」→「有効にする」（カードの登録を求められたら登録）
4. 左のメニュー「API とサービス」→「認証情報」→「認証情報を作成」→「API キー」→ 出てきたキーをコピー
5. キーの「API の制限」で「Cloud Text-to-Speech API」だけにしぼる（ほかに使われないように）
6. KAYO に「**KAYO、BAR広告の声の設定をして。キーは ○○**」と話しかける → KAYO がパソコンに設定し（環境変数 `GOOGLE_TTS_KEY`）、3人の声の候補を聞き比べられるように用意します
7. `07_アカウント管理/アカウント一覧.md` に「Google Cloud（読み上げ）」を1行足す（キーそのものは書かない）

## うまくいかないとき

| こまりごと | 直し方 |
|---|---|
| お客さんが承認ページで動画を見られない | Google Workspace の管理画面で「ドライブの共有：組織外への共有を許可」にする。または KAYO に相談 |
| 承認したのに受付台帳が「予約エラー」 | 履歴の欄に理由が出ます。KAYO に「予約エラーを直して」と話しかける（投稿時刻の前なら1時間ごとに自動でやり直します） |
| ページが真っ白・エラー | 手順1のファイルの名前がちがう（form.html ではなく **form**）。top・confirm・logo・photos・css・common のどれかがない・名前がちがうときも出る |
| 会員がパスワードを忘れた | トップページの「パスワードを忘れた方はこちら」から自分で再設定できる（メールが届く） |
| 会員の利用を止めたい | 受付台帳の「会員」シートで、その人の「状態」を **停止** にする |
| 「キーが違います」と出る | パソコンの BAR_API_KEY と、ログに出た API_KEY が同じか確認 |
| 「Google Apps Script のユーザーによって作成されたもの」と出る | Google が自動で出す表示（プログラムでは消せない）。消すなら alcoholiday.org（Google サイト）に受付サイトを埋め込む。承認ページ（メールのリンク）には残る |
| 申し込みから10分たっても承認のお願いメールが来ない | パソコンの電源が入っているか確認。`09_広告事業/自動制作ログ.md` と `案件/自動制作の記録.txt` を KAYO に見てもらう |
| 自動制作を止めたい | Windows の「タスク スケジューラ」で「ALCOHOLIDAY BAR広告 自動制作」を右クリック →「無効」 |
| プログラムを直した | 直したファイルを Apps Script に貼りつけて保存 →「デプロイ」→「デプロイを管理」→ 鉛筆 →「新バージョン」→「デプロイ」（「新しいデプロイ」は URL が変わるので押さない） |
