あなたのお店のおすすめを、SNS で届けよう

お店の Instagram・TikTok・X に載せる、おすすめ商品のショート動画をおつくりします。BAR・居酒屋・飲食店の集客や、おすすめメニューの紹介にお使いください。

スマホで撮った動画が、紹介動画に

動画を3本送るだけ。あとは ALCOHOLIDAY（アルコホリディ）が仕上げて、お店の SNS に載せられる動画にします。

動画を3本撮るだけ

1本5秒くらい。お店の雰囲気・おすすめの商品・自由の3本です。

声の案内と字幕で仕上げ

3本をつなぎ、声の案内と字幕を入れた1本の紹介動画（縦型のショート動画）にします。

見てからダウンロード

できあがった動画はメールでお知らせします。有料版は、読み上げの読み方を1回まで直せます。

SNS ごとの投稿文つき

Instagram・TikTok・X の3つの投稿文を、すべてお送りします。

申し込みの流れ

  1. Google のアカウントでログイン
  2. お店とおすすめ商品のことを入力
  3. 動画をアップロード
  4. メールで届いた URL から動画をダウンロード
  5. お店の SNS に投稿
  • 会員登録やパスワードはいりません。Google のアカウントでログインします。
